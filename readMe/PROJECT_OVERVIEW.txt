⚙️ NETLIFY BUILD PROCESS:

  When you push to GitHub, Netlify AUTOMATICALLY runs:

  $ npm install
    └─ Downloads React, Next.js, Tailwind, etc.
    └─ Time: ~1-2 minutes

  $ npm run build
    └─ Compiles TypeScript → JavaScript
    └─ Compiles React → HTML
    └─ Processes CSS with Tailwind
    └─ Optimizes everything
    └─ Time: ~1-2 minutes

  Deploy to CDN
    └─ Uploads built files to global servers
    └─ Website goes LIVE!
    └─ Time: ~30 seconds

  TOTAL TIME: ~5-10 minutes from git push to website live!
