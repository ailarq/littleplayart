🎯 THE 3 STEPS:

  Step 1: Create Folder in public/games/
  Step 2: Copy Game Files Into That Folder
  Step 3: Edit games.json with Game Info

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📂 STEP 1: CREATE FOLDER

  Location:
  /Users/lana/Claude/Projects/Saish_Page/public/games/

  Example: For "Flappy Bird" game

  Using Terminal:
  $ mkdir public/games/flappy-bird

  Or: Right-click in Finder → New Folder → Name it "flappy-bird"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📄 STEP 2: COPY FILES INTO FOLDER

  Saish gives you:
  ├── flappy-bird.html          (the main game)
  ├── flappy-bird.css           (styles, optional)
  └── flappy-bird.js            (code, optional)

  Copy to:
  public/games/flappy-bird/
  ├── index.html                (RENAME game.html to this!)
  ├── style.css                 (RENAME game.css to this!)
  └── script.js                 (RENAME game.js to this!)

  IMPORTANT: Main file MUST be named "index.html"!

  Using Terminal:
  $ cp flappy-bird.html public/games/flappy-bird/index.html
  $ cp flappy-bird.css public/games/flappy-bird/style.css
  $ cp flappy-bird.js public/games/flappy-bird/script.js

  Or: Drag and drop in Finder (rename as needed)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📝 STEP 3: EDIT games.json

  Open file:
  /Users/lana/Claude/Projects/Saish_Page/games.json

  Find the "games" array and ADD this:

  {
    "id": "flappy-bird",
    "title": "Flappy Bird Clone",
    "icon": "🐦",
    "description": "Navigate through pipes and avoid obstacles",
    "category": "Action",
    "difficulty": "Beginner",
    "playTime": "5-10 minutes",
    "date": "2026-10-09"
  },

  IMPORTANT RULES:
  • "id" must match your folder name exactly!
  • "title" is what users see
  • "icon" must be an emoji from the emoji list
  • "description" explains what the game does
  • "category" must be: Action, Puzzle, or Educational
  • "difficulty" must be: Beginner, Intermediate, or Advanced
  • "playTime" is estimated duration
  • "date" is YYYY-MM-DD format

  ❌ game.html                       ✓ index.html
